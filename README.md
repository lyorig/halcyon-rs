# halcyon-rs

This is an attempt at porting my [Halcyon](https://github.com/lyorig/halcyon) C++ SDL3 wrapper to Rust.
As I'm primarily a C++ developer, expect a lot of unsafe code and a general foot-gun attitude. My primary vision is getting as close to a zero-cost wrapper as possible, even if that means offloading safety guarantees to the library consumer.
